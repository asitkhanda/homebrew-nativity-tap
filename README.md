# homebrew-nativity-tap

Homebrew tap for [Nativity](https://nativity.asit.space), speech to text for Indian languages, now on the Mac.

```bash
brew tap asitkhanda/nativity-tap
brew trust asitkhanda/nativity-tap
brew install --cask nativity
```

The cask is bumped automatically when a new version is released from the private Nativity-MacOS repository; the DMGs live in [nativity-macos-releases](https://github.com/asitkhanda/nativity-macos-releases).
